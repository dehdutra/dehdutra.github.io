Como os dados são processados

  • São consultados arquivos CSV do diretório de dados de 10 minutos do INPE.
  • Os registros são filtrados para as últimas 24 horas e para o satélite de referência.
  • O mapa estadual contabiliza os pontos dentro de cada polígono GeoJSON.
  • Os dois mapas usam a mesma lista de focos filtrados.

Arquivos estaduais e limitações

O dashboard carrega os três arquivos estaduais locais. Os arquivos precisam conter geometrias GeoJSON válidas e cobrir os estados brasileiros sem duplicações. A contagem é espacial, não baseada apenas no nome do estado informado no CSV.

Dados de focos de calor: INPE · Programa Queimadas. Limites estaduais: arquivos GeoJSON locais fornecidos pelo usuário. Mapa-base: OpenStreetMap.
